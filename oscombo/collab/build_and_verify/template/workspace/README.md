# Northstar OrderDesk — local test project

This is a synthetic, offline order-list web application. The task is to repair
the filter behavior described in `requirements.md`. Run it through the CoDesk
Build-and-Verify case runner; do not connect it to any external service.

The project files and fixture are shared by A and B in every condition. A is
assigned implementation; B is assigned browser verification. Both can read
the requirements, code, fixture and visible test plan.
