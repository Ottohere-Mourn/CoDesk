# Computer-use agent framework review

**Decision (2026-09-27):** the original OSWorld paper's published baseline recipe is GPT-4o with screenshot observations and OSWorld's pluggable agent/environment runner. Given the existing local-only constraint, test OSWorld V2.1's first-party `Qwen3VLAgent` with the already-local Qwen3-VL-30B-A3B checkpoint as the first reusable local baseline. This is an OSWorld-native agent implementation; it is **not** the original GPT-4o baseline or a public leaderboard result. Do not extend the project's retired, custom `LocalQwenGUIActor` prompt/action format. The benchmark adapter should remain a narrow bridge between the agent's existing `reset()` / `predict(instruction, observation)` API and `ActorContext`.

## Local implementation boundary

The current integration keeps OSWorld's `Qwen3VLAgent` in charge of prompt construction, screenshot history, tool-call parsing, relative-coordinate scaling, and PyAutoGUI action generation. `LocalQwenInferenceClient` only forwards the agent's existing message payload to a loopback-only Transformers worker that loads local files; it does not create an alternate action schema. `OSWorldAgentActor` copies observations into `predict`, records the response and native action strings, and sends those strings through `ActorContext.execute_gui_action`. The evaluator remains outside the actor and model process.

## Adapter changes required

1. **Environment adapter:** expose a narrow `execute_gui_action(str)` bridge that forwards OSWorld-native PyAutoGUI code through the existing role-checked GUI path. Preserve actor ID and observed revision in the event log. Do not add a second coordinate system or tool schema.
2. **Actor bridge:** implement the OSWorld agent lifecycle as a benchmark actor: `agent.reset()` once per episode, then `context.observe()` → `agent.predict(task, obs)` → execute returned native action strings. Bound episode steps, retain screenshot hash/resolution, raw model response and action list, and stop on the agent's native `DONE`/`FAIL` result.
3. **Inference transport only:** replace the hosted transport call on the pinned agent instance with loopback HTTP to a worker loading local weights. Keep its messages and response text unchanged. Do not expose evaluator state to the worker.
4. **Shared scheduling, after solo success:** the current wrapper runs a complete agent turn sequence to terminal. Before using it in interleaving conditions, add a resumable one-prediction `step()` surface to the wrapper (not to the planner) so Orchestrator controls when the agent observes and acts. The exact same agent object/history must persist across turns. Do not declare this shared integration complete until solo passes and interleaving is exercised in the same Guest.

## Recommended integration order

1. Run OSWorld V2.1 `Qwen3VLAgent` unchanged against the current desktop action executor, using the existing local Qwen3-VL-30B-A3B weights and evaluator-hidden Writer solo task. Save per-step screenshots/actions and reset evidence.
2. If local MoE loading or latency blocks, retry its supported 4B checkpoint without changing agent protocol; report model size as a factor. Do not fall back to bespoke scripted/mock inference.
3. After one solo office task passes evaluator and reset, refactor only the bridge into resumable agent turns. Run solo, sequential and naive interleaving using the same task and model, then focus-aware scheduling if the actor API can expose focus metadata without changing OSWorld's planner.
4. Add SeeAct only for browser tasks that genuinely require a browser-page/DOM action interface. Keep it in a browser-specific adapter.
5. Consider CogAgent as a separately versioned adapter after checkpoint/license/runtime verification. Consider UFO only if the environment moves to Windows. Add Anthropic/OpenAI adapters only when hosted model access is explicitly in scope.

## Validation status

The comparison above is interface/source inspection, not a claim that each framework was executed here. Local weight availability and hardware were checked. The OSWorld-native Writer solo episode passed its programmatic evaluator and reset; a real same-Guest agent+scripted sequential attempt was then run but failed before the second actor received a turn. Outcomes and per-episode artifacts are in `TEST_RESULTS.md`. No model shared-interference result is claimed.
