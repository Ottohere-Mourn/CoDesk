## 二、底座隔离与五道重构任务设计矩阵

### 2.1 评测底座 `experiments/novel_frontier_v1.py` 架构修复

1. **切断 `guest_bash` 对桌面 GUI 的旁路访问**：角色 CLI 容器仅共享 `--network` 与 `--pid`，**不再挂载 `:99` `/tmp/.X11-unix`、`AT-SPI` 总线、`DISPLAY=:99` 或共享 `~/Downloads`**；`LibreOffice` 改用桌面容器本地 UNIX 命名管道 `uno:pipe,name=nf_uno_pipe;urp;` 替代回环 TCP `:2002`，杜绝 CLI 无头脚本绕过 GUI 驱动。
2. **100% 只读收卷（`stop_and_grade()`）**：彻底移除收卷时的 `xdotool key ctrl+s` 注入，通过 `inspect_live_uno_documents_readonly()` 与 `inspect_live_blender_readonly()` 只读核查运行态窗口脏缓冲（`isModified` / `bpy.data.is_dirty`）与磁盘文件一致性。
3. **消除低步数截断、刚性分屏与跨角色目录偷看**：`max_cua_calls = 180`、`conc_role_timeout_s = iso_role_timeout_s = 1080s`；启动采用 Openbox 自然窗口放置；Track-2（`NF-11, NF-13, NF-14`）为每个角色分配独立私有 `/workspace`，仅将真正的共享业务工件挂载在 `/workspace/shared_docs`；`isolated` 模式仅启动当前单角色所需桌面窗口并按 `active_roles` 范围判分。
