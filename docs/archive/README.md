# Historical Development Records

This archive preserves development reports, superseded designs, infrastructure notes, and pilot evidence. These files are historical records, not the current user path. Use the repository [README](../../README.md), [Quick Start](../getting-started/QUICK_START.md), [benchmark overview](../research/BENCHMARK_OVERVIEW.md), and [handoff](../handoff/HANDOFF.md) for the current suite and next steps.

## Archive groups

- [`design/`](design/) — prior positioning, novelty reviews, task designs, taxonomy drafts, and workflow plans.
- [`runtime/`](runtime/) — runner, adapter, backend, and performance engineering records.
- [`experiments/`](experiments/) — smoke, pilot, model, task validation, failure, and result reports.
- [`migration/`](migration/) — host, inference, and frozen shared-filesystem migration investigations.
- [`resources/`](resources/) — GPU/resource audits and capacity reports.

Historical conclusions may be superseded. Check each record's version, topology, evidence level, and date before citing it. `benchmarks/codesk_v1/` is retained legacy data; `benchmarks/codesk_v1_final/` is the only current V1 suite.
