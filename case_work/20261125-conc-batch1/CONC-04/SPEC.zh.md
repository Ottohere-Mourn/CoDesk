## 2. 运行环境与服务初始化

### 2.1 浏览器窗口重叠布局与鉴权

* Setup 阶段在 Guest 桌面启动 **2 个相互重叠的 Google Chrome 窗口**，初始窗口尺寸均为 `1280x840` 且共同覆盖屏幕中央工作区，确保任一窗口置顶时均会遮挡另一窗口的核心画布区域。

* 两个本地服务均采用非阻塞后台子进程启动、暴露 `GET /health`，并通过**仅存浏览器内存的 `HttpOnly` Session Cookie** 预登录（不落盘、无明文账密、无 Cookie 返回 `401`）。

### 2.2 本地服务 A：`http://127.0.0.1:18091`（FlowCanvas 架构图编辑器）

* **页面功能**: 现代矢量画布编辑器，核心 `<canvas>` 尺寸 `1000x680`，右侧含 2 个可浮动属性面板。

* **初始元素**:

  * 左侧停靠栏停放 6 个可拖拽架构模块卡片：`API Gateway`, `Auth Service`, `Order Engine`, `Inventory DB`, `Event Bus`, `Billing Worker`。

  * 画布上标有 6 个带对应名称的虚线目标槽位，以及 2 块醒目的红色禁区障碍矩形（`#E53935` 斜纹填充）。

* **交互与后端留痕**:

  * 须通过鼠标拖拽将 6 个节点放入对应目标槽位（中心偏差 `<= 25px`），并从节点连接锚点拖出 7 条指定有向连线（支持折线锚点绕行，连线线段不得与任意红色禁区矩形相交）。

  * 前端校验真实指针拖拽轨迹（`pointerdown` -> 至少 3 次 `pointermove` -> `pointerup`），记录中途因窗口失焦/遮挡被打断的拖拽次数，点击提交后由后端落盘校验日志并允许导出 JSON。

* **视觉校验标识**: 页面右上角固定渲染 `120x24px` 纯色识别条 `#00897B`。

### 2.3 本地服务 B：`http://127.0.0.1:18092`（MetricAnnotator 时序异常标注台）

* **页面功能**: Grafana 风格时序监控图表标注界面，共加载 4 张高分辨率光栅监控图表（`chart_1`: `CPU Load`, `chart_2`: `API Latency`, `chart_3`: `Memory Usage`, `chart_4`: `Request Throughput`）。

* **图表素材生成**:

  * 由 Setup 使用 Python（`matplotlib` 或 `Pillow`）程序化绘制 4 张 `960x540` 专业监控折线图 PNG（含标准坐标轴、浅灰网格线、时间戳刻度、图例与警戒阈值虚线）。

  * 每张图表精确包含 **2 处明显异常区间**（共 8 处），类别限定为 3 种：

    * 快捷键 `1` -> `SPIKE`（远超警戒虚线的尖峰突刺）

    * 快捷键 `2` -> `DROP`（断崖式骤降至接近零值）

    * 快捷键 `3` -> `FLATLINE`（长时间完全水平卡死的直线段）

  * 8 处异常的真值边界框坐标仅存于后端校验器内存中，严禁通过 HTML、JS 或 API 暴露给前端。

* **交互与后端留痕**:

  * 在 `<canvas>` 图表上通过鼠标按住拖拽画出异常边界框，选中框后按键盘数字键 `1`、`2` 或 `3` 分配对应类别（按 `Delete` 或 `Backspace` 删除选中框）。

  * 前端校验真实指针拖拽序列与键盘分类按键事件，每张图标注完成后点击提交，全部完成后导出 `/workspace/out_b/anomaly_labels.json`。

* **视觉校验标识**: 4 张图表视图右上角各自固定渲染 `120x24px` 唯一纯色识别条：

  * `chart_1`: `#3949AB`

  * `chart_2`: `#00838F`

  * `chart_3`: `#6A1B9A`

  * `chart_4`: `#EF6C00`

## 5. 防作弊与工程实现约束

1. **专业图表渲染**: 4 张时序图表须使用标准统计绘图样式（清晰的坐标轴、网格线、图例、阈值虚线与平滑数据曲线），严禁使用低质简笔画风格。

2. **真值严格隔离**: 异常坐标真值仅保留在服务端内存中用于评分，前端仅接收静态光栅 PNG 图像与用户交互绘制数据。

3. **冲突指标埋点**: 除常规框架指标外，两服务额外记录因窗口失焦导致的拖拽中断次数（`aborted_drag_count`）及误路由数字键/删除键次数，并保留关键运行截图与最终交付截图供次日抽检。
