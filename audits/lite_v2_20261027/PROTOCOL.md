# CDD-LITE-002 v2 experiment protocol (frozen before model runs)

The task, three public fixture files, role prompts, hidden Gold and artifact Oracle live in `oscombo/collab/data_to_deck_lite_v2/`. V1 and original case assets and experiment runs are untouched. The evaluation target is one genuine saved-workbook handoff followed by one saved Impress conclusion. The 12-call scripted path validates the GUI, not model performance.

Before model use: run offline Gold/negative controls, real Shared and Isolated scripted positive controls, and a real GUI negative control. Inspect actual screenshots, recovered files, revision propagation, peer read-only permissions, GUI reopen and reset. A failed bridge/setup is infrastructure-invalid, not an Actor failure.

Model: `gpt-6-astra` at the existing compatible Responses endpoint, medium effort; private credential only in coordinator/relay. Two separate actors start concurrently. Each has 25 desktop-tool calls and 900 seconds in the full pair. The same prompts, public fixture bytes, tool catalog, model, budget, postscore Oracle and task-root paths apply in both conditions. The Shared Guest has two independent agents and one desktop with no input lock. Isolated has two Guests, read-only peer copies, the same message/attachment tools and saved-version bridge. Run one bounded Isolated pilot to check model/tool viability, then exactly one full Shared and one full Isolated episode. Do not adjust task or retry on a condition-specific score.

Report A, B and joint Oracle outcomes, saved-revision/message chronology, active overlap, model/API and GUI times, token use, setup/reset time and Guest resources. Separately classify focus theft, application state changes, bridge delay and ordinary model mistakes from screenshots/actions. A message or citation alone does not establish handoff; require a saved A revision before A's result message, B's read/consumption trace, and B's final saved revision after that handoff. If this behavioral criterion fails while artifact Oracle passes, report that distinction.
