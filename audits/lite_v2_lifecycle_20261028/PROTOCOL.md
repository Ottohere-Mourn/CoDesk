# Lite v2 lifecycle repair: frozen formal protocol

Freeze date: 2026-10-28, after offline tests and one real concurrent Isolated diagnostic Pilot. The first Pilot (`cdd-lite-v2-life-pilot-isolated-20261028T083300Z`) used 15 desktop calls and 720 seconds per role. A saved the correct workbook, B entered the correct slide text, but the 720-second timer killed B's `ctrl+s` call before it returned; B Oracle failed. This is a retained time-budget diagnostic, not a condition score. No handoff suspension was triggered because B did not voluntarily exit.

Formal pair: one Shared then one Isolated, unique run IDs, same `gpt-6-astra` medium model, same public v2 Fixture and role Prompt, same 25 desktop calls and 1200 seconds per role, same API relay, same messages/attachments/artifact bridge and same hidden Oracle. `--handoff-lifecycle` is on in both. There is no desktop input lock. No task content, Gold or Oracle is sent to Actors. Any infrastructure failure is preserved as invalid, not silently retried as a model score. A failed model run is not replayed for success selection.

Completion gate: only B has a declared external dependency on A. If B's Codex process exits normally with no own published revision while A's message and new saved revision have not both arrived, or the newest A message arrived but was not returned by B's `read_messages`, the coordinator logs suspension. It waits without B model calls or desktop calls and resumes the **same** private Codex session after the two public handoff signals arrive. The wake prompt tells B only to inspect messages and revisions and continue its original task. It does not include a result value. The original desktop-call counter and the single 1200-second role deadline remain in force. A final reply after B has read A's latest handoff is treated as a model choice, not automatically retried. If A never hands off, B's wait expires and the episode is scored accordingly.

Report artifact Oracle, A/B/joint outcome, saved revisions/messages and B's actual read, suspension/wake events, model requests and desktop calls during wait (expected zero), active overlap excluding suspension, API overlap, GUI action overlap and focus changes, tokens, setup/total time, QEMU CPU/RSS. Do not infer focus interference from a joint failure alone. Keep the 2026-10-27 v2 experiments unchanged.
