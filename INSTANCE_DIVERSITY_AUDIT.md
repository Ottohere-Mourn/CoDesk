# CoDesk V1 Instance Diversity Audit

Status: generated by `scripts/audit_instance_suite.py` from the committed fixed manifest. The audit is about instance data diversity, not runtime task validity.

## Audit method

The audit checks duplicate semantic signatures, Actor goal-pair signatures, fixture hashes, structural signatures and normalized structure. Normalization removes IDs and literal values but retains workflow/operation graph, domain schema, target-object identities/schema and target/guard layout. A pure ID/text/name substitution is therefore insufficient. Different target cells/ranges, range shapes, record or route schemas, semantic domain and guard placement remain explicit axes. The audit records generated/retained/rejected per workflow; rejected rows are never silently overwritten.
